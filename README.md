# InstAlert Landing Page

Landing page comercial de InstAlert, una plataforma SaaS desarrollada por LosIncreiblesCorp para conectar negocios locales mediante alertas de seguridad, información de riesgo y colaboración comunitaria.

## Características

- Diseño responsive para escritorio, tablet y dispositivos móviles.
- Navegación adaptable con menú móvil.
- Soporte bilingüe en inglés y español.
- Sección informativa sobre el producto y sus beneficios.
- Visualización de soluciones y red de negocios.
- Planes de suscripción con precios en PEN y USD.
- Presentación del equipo de LosIncreiblesCorp.
- Llamada final a la acción y enlaces de soporte y documentos legales.
- Componentes visuales creados con HTML y CSS.
- Iconos proporcionados por Lucide.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Lucide Icons
